═══════════════════════════════════════════════════════
 WHY IT WORKS NOW
═══════════════════════════════════════════════════════

Before:
  - activeChat had inline style="display:none; flex:1"
  - This broke flexbox layout
  - Children couldn't calculate heights

After:
  - activeChat uses CSS class
  - Proper flexbox hierarchy
  - height: 100vh constraint
  - overflow-y: scroll !important
